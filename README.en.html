BX Modified Ticker

Configurable, multilingual news ticker for modified eCommerce. Displays current messages (e.g. shipping notices, promotions, service notices) as an endlessly scrolling ticker bar in the storefront – fully managed through the admin interface, no template changes required.

Features

Message management

  • Any number of ticker messages, sortable via drag & drop or arrow keys.
  • Each message can be enabled/disabled individually.
  • Multilingual text per message – if a translation is missing, the shop's default language is used as a fallback automatically.
  • Optional link per message (only relative paths or http(s):// are accepted).
  • Scheduled display via "from"/"to" dates (e.g. for time-limited promotions).
  • Freely editable label on the left of the ticker (e.g. "Current"/"Live"), also multilingual.

Presentation & behavior

  • Speed, gap, font size, padding and edge fade are freely configurable.
  • Scroll direction (left/right) and position (in the normal document flow at the top, or fixed at the bottom of the screen).
  • Font (shop font, system sans, serif, monospace) and font weight (normal/semibold/bold).
  • Colors for background, text, accent (live dot) and dividing lines via color picker.
  • Pause on hover/keyboard focus can be toggled.
  • Automatically respects prefers-reduced-motion (cannot be disabled) – the animation is turned off for affected users.
  • The ticker duration is calculated automatically in the frontend based on the actual text width, so the speed stays constant regardless of the amount of text.
  • No empty ticker bar is shown if there are no active/valid messages.

Output type: Standard or Smarty

  • Standard: the ticker markup is output automatically in the frontend (at the top of the HTML flow or fixed at the bottom).
  • Smarty: no automatic output – instead only the global Smarty template variable {$bx_modified_ticker} is populated, which can be placed freely in your own template. The position setting (top/bottom) has no effect in this mode, since placement is entirely up to the template.

Admin interface

  • A single, cohesive configuration panel with live preview (changes take effect immediately in the preview ticker).
  • Language switcher for all managed texts (label, messages) directly in the panel.
  • JSON preview of the values as they would be stored (collapsible box for developers/support).
  • Saving runs asynchronously via AJAX, including success/error feedback.

Security & robustness

  • CSRF protection via the shop's global mechanism (CSRFName/CSRFToken).
  • Server-side validation of all inputs: numeric values are clamped to sensible ranges, colors are checked for valid hex values, choice fields (direction, position, type, font, font weight) are validated against whitelists.
  • Links are restricted to relative paths or http(s):// (no javascript:/data: etc.).
  • Free text is stripped of HTML/tags and length-limited.
  • Saving is performed within a database transaction (rollback on errors).
  • Frontend output is consistently HTML-escaped.

Database

The module creates the following tables on installation:

  • bx_ticker_items – messages (sort order, status, link, validity period)
  • bx_ticker_items_description – multilingual text per message
  • bx_ticker_label – multilingual ticker label

as well as the configuration values in a dedicated group under Configuration.

Requirements

  • PHP ^7.4 or ^8.0
  • modified eCommerce 3.1.0 – 3.3.0
